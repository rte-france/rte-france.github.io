The OpenTelemetry Collector is a vendor-agnostic service to receive, process and export telemetry data (metrics, logs and traces). It is a project of the Cloud Native Computing Foundation (CNCF).

RTE contributes to the OpenTelemetry Collector by submitting patches for issues detected while working on the [SEAPATH project](https://opensource.rte-france.com/projects/seapath), where it collects the metrics of the cluster.

Example: [\[exporter/prometheus\] Remove every stale series in a metric](https://github.com/open-telemetry/opentelemetry-collector-contrib/pull/51289)
